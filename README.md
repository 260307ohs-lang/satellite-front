# 위성 전선

위성 사진 같은 지도 위에서 군대를 지휘하는 웹 전략 게임입니다. 설치 없이 브라우저에서 바로 실행됩니다.

생산·건설·훈련·외교는 자동으로 돌아가고, 플레이어는 **군사 이동과 공격**만 지휘합니다.

## 실행

- 온라인: GitHub Pages 주소에서 바로 플레이
- 오프라인: `index.html`을 내려받아 브라우저로 열기

## 주요 기능

- **위성 사진 지도**: 산맥 음영, 숲, 농경지, 사막, 도시 블록과 도로, 해안 물거품, 흘러가는 구름
- **전투 효과**: 포탄 섬광, 연기, 예광탄, 폭발, 항복 백기
- **작전 고문**: 작전안을 짜 주면 고르기만 하면 됩니다
- **명령**: 빈 땅 점령 임무, 국경 배치 대열(균등·위협 비례·2열 종심·집중·양익 포위·쐐기 돌파·직접 지정)
- **전투 규칙**: 보급·지형·기갑 관통, 수적 열세 항복, 수도 총동원, 나라마다 다른 도시권

## 조작

| 조작 | 동작 |
|---|---|
| 사단 클릭 | 선택 |
| 땅 클릭 | 이동 |
| 적 땅·전투 클릭 | 공격 |
| Shift + 드래그 | 여러 부대 선택 |
| 스페이스 | 일시정지 / 재개 |
| 1 · 2 · 3 | 게임 속도 |
| C | 구름 켜기·끄기 |
| F9 | 성능 표시 |
| Esc | 선택 해제 |

자세한 규칙은 게임 안의 「도움말」에 있습니다.

## 저장

진행 중인 게임은 브라우저(IndexedDB)에 자동 저장됩니다. 다른 브라우저나 기기와는 공유되지 않습니다.
